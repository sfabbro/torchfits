## User-visible changes → required doc updates (R15) + changelog

1. `FITSScaleColumns` scaling now computes **float64** (was float32) — bit-identical to `table.read_torch` output; `TNullToNan` promotes integer columns to **float64** (was float32) and leaves floating dtypes untouched (was: non-float32/64 → float32). Docs: `api-transforms.md` FITS-Metadata section gains the table-float64 vs image-float32 asymmetry note (this is the 2.0 float64-image backlog item's mirror).
2. `FITSHeaderScale.from_path` / `FITSHeaderNormalize.from_path` raise on IO errors and non-numeric keyword values (were: silent identity); absent BSCALE/BZERO still default per the FITS standard. Changelog `Fixed`.
3. `state=` kwarg now cannot mask a conflicting payload-declared state (conflict → `DataStateError`); documented as the `forward()`-input prior; `inverse()` validates against the produced state. Changelog `Fixed` (double-scaling guard).
4. `FITSHeaderNormalize` `scale_floats=True` inverse limits are per-thread; `inverse()` must run on the thread whose `forward()` produced its input. Instances remain picklable (thread-local cache dropped on pickle; a fresh worker re-runs `forward()`).
5. `AsModule`/`as_module` now preserves state stamping (nn.Sequential pipelines enforce the state machine end to end). Changelog `Fixed`.
6. `FITSScaleColumns`/`TNullToNan` raise a typed `TypeError` for non-column-dict inputs; a tensor column named `state` is treated as data by the state machine.
7. Doc items (a)–(e) of r2a-12.

## Invariants re-checked in slice

- `tnull-read-torch`: TNullToNan now bit-matches the reader's NaN columns (test `test_tnull_matches_reader_nan_columns`); raw integer TNULL without TSCAL stays a sentinel upstream (reader unchanged).
- `docs-api-sync`: export surface unchanged — `__init__.py::__all__` byte-identical, no new public symbols (new helpers `_table_linear_apply`, `_table_linear_remove`, `_require_columns`, `_read_header_floats` only).
- `minimal-diff`: 4 src files touched only; dead-code deletion is zero-behavior (r2a-15).
- Round invariant "one instance safe under `-J` worker threads": enforced for this slice by `TestInstanceThreadSafety` (stateless + `fits_meta` paths incl. the warn path and both `FITSHeaderNormalize` modes).
