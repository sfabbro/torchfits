Conventions established/verified (rubric class 1/7):
- **valid = finite**: `_get_valid_mask` now `torch.isfinite(x) & mask` (`True` = valid, end to end). This matches the changelog:428 claim ("valid mask is seeded from finite values") which the code (`~torch.isnan`) contradicted, and matches the `torch.isfinite` convention already used by `_weighted_quantile`, `_weighted_dispersion`, `_zscale_iraf` and `GlobalScalarNorm` mean/rms. NOTE for integration owner: `tests/transforms_reference.py:_median`/`sigma_clip_naive` still seed with `~np.isnan` — fine for all existing finite/NaN fixtures, but the oracle would diverge from the implementation on ±inf inputs. Oracle is read-only; recorded here rather than changed.
- **weighted= edge behavior (defined + pinned)**: constant data -> (c, 0); zero total weight (all ivar <= 0, all masked, or empty group) -> (NaN, NaN); non-finite ivar weights (incl. +inf "zero variance") are invalid samples -> NaN when a group has none left; `weighted=True` without `ivar` is an exact no-op (torch.equal). Tests: `TestWeightedStatsContracts`, `TestEmptyInputContracts`.
- **empty input**: empty reduction groups return NaN for median/quantile/weighted stats and the all-masked sentinels (+inf/-inf) for amin/amax (so `MinMaxNormalize` maps them to NaN exactly like all-masked groups); zero-size batch tensors flow through with defined shapes. `MeshBackgroundSubtract` on a pixel-less image is a shape-preserving no-op.
- **complex inputs**: stats transforms raise `TypeError` instead of silently discarding the imaginary part (previously a torch `UserWarning` + wrong real-only result).
- **integer inputs**: no integer-dtype NaN/inf sentinel construction anywhere (three sites crashed with `RuntimeError: value cannot be converted to type ... without overflow`); outputs follow the documented promotion (int32/int16 -> float32, int64 -> float64).
- **float16**: all stats/thresholds compute in float32 (`_stats_upcast` promotes f16/bf16), so `eps` floors no longer underflow to 0 in f16 (which produced `x / 0 = inf`).

Per-fix evidence (before = failing run against unfixed code; after = passing run). All runs: `pixi run pytest tests/test_transforms.py -q` on the same host.
