## Deferred (site + evidence)

- `caches.py:get_cached_hdu_type`/`set_cached_hdu_type` cannot store negative HDU-type probes (`None` doubles as "miss" in the `str | None` contract consumed by `_read_pipeline.py:249`); after r4c-09 the probe cost is paid once per file replacement, so the remaining win is marginal — needs a sentinel contract change across slices.
- `caches.py:_check_read_cache_locked` stale-hit path runs `invalidate_path()` (→ `handle.close()` IO) while holding `cache_lock` (RLock — re-entrant, no deadlock; contention-only on stale hits). Deferred as a lock-granularity change with no measured ≥5% evidence (perf class 4 evidence rule).
- `caches.py:_clone_read_value` clones tensors/lists one level deep; a nested dict-of-tensors payload would alias the cache. No current read result has nested dict payloads (all dict[str, Tensor | list]); revisit if result shapes grow.
- `hdu_api.py:find_first_hdu` per-HDU metadata probes (`get_hdu_type`/`get_shape`/`read_header_fast`) keep their documented skip-on-failure fallbacks (narrowing them risks mock/fake-handle consumers; failures only skip a *candidate* HDU and never serve data).
- `paths.py:has_bz2_support` `except Exception: return False` kept: capability probe whose documented answer on any load failure is "no bzip2" (not IO; no data path).
