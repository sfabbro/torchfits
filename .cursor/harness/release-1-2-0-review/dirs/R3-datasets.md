## Round-emphasis re-derivation (plan §R3)

- **`FitsTableIterableDataset` sharding (contiguous row ranges)** — lives in `data/__init__.py` (slice B). Re-derived at HEAD: `_shard_row_range` + `_row_window` are an **exact** partition (contiguous, near-equal, leftovers to first slots; `world_size·num_workers > nrows` → empty windows early-returned; no duplicates/misses for uneven rows). Pinned end-to-end through the class with fake DataLoader workers: `TestTableSharding::test_partition_exact_for_uneven_and_oversized_worlds` parametrized `(1,1) (2,2) (3,2) (4,3) (16,2)` over an 8-row table (uneven 6-slot split; 12- and 32-slot worlds exceed the row count) asserting the union of yielded rows equals all 8 rows exactly once. `len()`-vs-yield: `TestIterableFileSharding::test_iterable_epoch_yield_matches_map_len` (iterable epoch count == `len(FitsTensorDataset)` == file count) and the partition tests pin total yield == row/file count. No defect in B's sharding math; the rank-pair contract defect was in my `_resolve_rank_and_world_size` (r3a-08).
- **Shuffle determinism across workers/epochs; ranks disjoint** — `TestIterableFileSharding::test_shuffle_deterministic_and_shards_disjoint`: same seed ⇒ identical order across epochs and across re-instantiated workers; worker shards and rank shards disjoint and covering (incl. `shuffle_buffer_size` path). Holds at HEAD and after the `_shard_work_plan` dedupe.
- **`spectral_slice` bounds** — pinned: `stop` beyond extent clamps (`(3,99)` → 2 planes), `start` beyond extent yields an empty leading axis with dtype preserved, `(-1,2)/(3,3)/(4,2)` raise `ValueError` at construction. Axis-placement defect = r3a-01.
- **DQ `bad_bits` end-to-end (`True` = valid)** — re-derived: `_as_validity_mask` delegates to `transforms.mask_from_dq` (R2): 0-based bit *positions*, `bad_bits=None` ⇒ non-zero invalid, result `True`=valid; agrees with `transforms/mask.py` exactly. End-to-end pins exist (`TestImageMaskCompanions`, incl. `estimate_background`/`SigmaNormalize` on the decoded mask); no change needed.
- **`discover_bands`/`from_bands` zeropoints** — formula `10**(-0.4·ZP)` matches the documented `mag = -2.5 log10(counts) + ZP` convention; defects found = r3a-06 (`band_zeropoints` over-reporting) and r3a-07 (silent non-per-second factor).
- **`read_images_batch` fallthrough / `NAXIS2→0`** — r3a-17 (record-only; R4/R5/R6).
- **`make_loader` double-download** — r3a-12 (split fix, count proof + sibling micro-timing).
- **Worker-split block ×3** — r3a-14 (mechanical dedupe, outputs pinned unchanged).
- **Staged-cutout cleanup races** — r3a-02 (+ r3a-11 dup-URL leg).

## Owed doc updates (R15)

1. `docs/api.md` data module: new typed errors — `_resolve_rank_and_world_size` `ValueError` for `rank >= world_size`/negative; `FitsStagedCutoutIterableDataset(cutout_size<=0)` `ValueError`; `BandInfo.flux_scale(exptime_normalized=False)` `ValueError` without positive `EXPTIME`; table-column spectra (`column=`) reject multi-HDU and non-integer HDUs at construction.
2. `docs/api.md`/`docs/compatibility.md`: `FitsStagedCutoutIterableDataset` staging semantics — `cleanup=True` stages per-iterator under `<staging root>/it-*` and removes it at close; `cleanup=False` reuses the shared staging root and never deletes; copies for URLs occurring more than once survive until the iterator closes.
3. `FitsImageDataset.band_zeropoints()` now reports only the dataset's flux HDUs (was: every flux extension in the file).
