## User-visible changes (owed docs at R15 — r4a-15)

1. `torchfits.read_batch([paths])` now raises `RuntimeError` naming the first bad path instead of skipping it with a `RuntimeWarning` and returning a shortened list (`strict=True` re-raises the original error unwrapped). `read([paths])` behavior on bad paths is unchanged (it already raised naming the path).
2. Fallback read errors: `OSError`/`FileNotFoundError` now propagate typed instead of being wrapped in `RuntimeError`; table-reader fall-through dispatches on exception type (never message) and surfaces the primary reader's error when all readers fail (truncation messages unchanged).
3. `read(handle_cache_capacity=)` warns with the pinned literal from `tests/test_deprecated_knobs.py`.
4. HTTP Range cutouts reuse the open-time header walk (perf only, same results).
