# Evaluation

Benchmarks, upstream parity against astropy and fitsio, migration notes, and
CANFAR runs live in
[torchfits-harness](https://github.com/astroai/torchfits-harness).

Torchfits keeps the library, the API, and tests that do not import those
packages. Install a torchfits wheel into the harness environment and run the
comparison there.
